# El Test de Escudos de Belén ✨🎀

Juego interactivo y didáctico de escudos de fútbol con estética coquette, diseñado con mucho amor para Belén.

## 🌸 Características

- **150 escudos de fútbol** organizados por categorías:
  - 🇦🇷 **40 Clubes Argentinos**
  - 🌴 **25 Clubes Latinoamericanos**
  - 🌍 **35 Federaciones y Selecciones Nacionales**
  - 🏰 **50 Clubes Europeos**
- **2 Modos de juego:**
  - 🎀 **Flashcard (1 a 1):** Adiviná el club/selección y tocá para revelar la respuesta con confeti y efectos de sonido.
  - 📖 **Álbum de Stickers (150):** Cuadrícula completa interactiva con filtros por país, liga o estado (acertados, para repasar o pendientes).
- **Offline & Standalone:** Todos los escudos están guardados localmente en alta resolución (SVG y PNG transparente).
- **Sonidos coquette:** Efectos auditivos dulces usando la Web Audio API nativa.
- **Persistencia:** Guarda el progreso en `localStorage` para no perder las respuestas.

## 🚀 Despliegue

Sitio web estático listo para desplegar en cualquier proveedor (Vercel, GitHub Pages, Netlify).
